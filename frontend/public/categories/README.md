# Ilustrações de categorias inGarage

Oito ilustrações vetoriais originais criadas para este projeto, sem fotografias, marcas ou assets de terceiros. Podem acompanhar o uso comercial da loja sem depender de bancos de imagens ou atribuições externas.

Todas usam enquadramento 4:3 (640 × 480), fundo claro, objetos em grafite e laranja e composição central. Os arquivos SVG são leves, escaláveis e não contêm scripts, fontes, links ou recursos externos.

O frontend escolhe a ilustração pelo nome e caminho da categoria. Imagens específicas fornecidas pelo catálogo têm prioridade; se falharem, a ilustração correspondente é exibida. Categorias novas usam a ilustração mais próxima ou o conjunto de acessórios.
